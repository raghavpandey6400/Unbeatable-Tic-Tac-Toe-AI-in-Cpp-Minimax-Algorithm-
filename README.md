# Unbeatable-Tic-Tac-Toe-AI-in-Cpp-Minimax-Algorithm-
C++ Tic-Tac-Toe with an unbeatable AI. It uses the Minimax algorithm to evaluate every future board state, guaranteeing a win or a tie. I added depth-scoring so the AI plays aggressively—hunting for the fastest possible win while delaying any forced losses.
